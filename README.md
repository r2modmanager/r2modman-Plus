# r2modman Plus (v3.2.21)

Isolated profile manager for Valheim, Lethal Company, Risk of Rain 2, and Thunderstore communities - keeping base Steam directories untouched on PC and Linux.

### What Changed in 3.2.21
1. **CCDN Mirror Support**: Faster package index fetches and resilient downloads.
2. **MIO Modloader & Lovely**: Built-in MIO installer support and state-file clean uninstalls for Lovely.
3. **Linux & Localization**: Official Flatpak metainfo XML alongside `zh-CN`, `KO`, and `FR` UI translations.

### Sharing a Profile Code
Export any profile as a compact code or file via `ProfileImportExport` (`Buffer` provider) so co-op lobbies sync identical BepInEx, MelonLoader, or MIO versions in seconds.
